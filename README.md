# DSH AI 修图助手

一个为 DeepSeek Harness Desktop 设计的 Windows 修图 Agent。它先只读遍历并分析照片，再由用户逐步确认入选图片、风格、裁剪、人物/动物精修强度、调色、局部修改和导出方案；确认后才通过桌面控制操作 Photoshop、像素蛋糕或用户指定的软件。

## 核心能力

- 识别人像、风景、动物、产品、建筑、纪实、夜景等多标签场景，并按光线、质量和用途推荐 2–3 个可执行风格方案。
- 操作 Windows 上的 Photoshop 和像素蛋糕，默认前台可见，关键动作后截图复核。
- 强制人工确认：筛图完成、风格选择以及每个编辑阶段都暂停，未经确认不继续。
- 非破坏式工作流：原图只读、工作副本、智能对象/调整图层/蒙版、分阶段版本和可回退操作。
- 人像、风景、动物和批量任务的专项质量检查；支持样片确认后再同步整批。
- 上传隐私门：向像素蛋糕或其他云服务上传前，必须列出具体文件和用途并再次确认。

## 安装

需要 Windows 10/11、DeepSeek Harness Desktop `0.2.1-rc.3` 或兼容的 `0.2.x` 版本，以及能接收图片输入的模型路线。

```powershell
dsh plugin --profile desktop add github:wly63227/dsh-photo-retouch-agent
```

安装后完全退出并重启 DeepSeek Harness Desktop，新建会话，在 Agent 选择器中选择“AI 修图助手”。首次使用前在插件页确认 `dsh-computer-use-win` 工作正常。

## 使用示例

```text
遍历 D:\Photos\Trip，只做只读筛选。先给我候选清单和预览，我确认入选后再进行风格设计；后续每一步都等我确认。
```

```text
先从这组人像中挑出清晰、表情自然的候选。给我三种风格方向，不要上传任何照片，等我决定是否使用像素蛋糕。
```

## 确认协议

默认状态机为：只读遍历 → 等待选片 → 图像诊断 → 等待风格 → 提议单步操作 → 等待确认 → 执行并截图 → 用户复核 → 下一步。用户可以显式授权一组同类操作，但异常图片仍会停下复核。

这个插件不会替用户做最终审美决定，也不会默认覆盖、删除或上传原图。外部桌面控制能力由固定版本 `dsh-computer-use-win@0.5.2` 提供；请同时审阅其权限和设置。

## 开发与验证

仓库已经包含可直接安装的 `cordis.patch.yml`。DSH 会从该文件加载 Windows 桌面控制适配器和 `photo-retouch` Agent 预设，技能摘要位于 `skills/photo-retouch-agent/`。修改配置后，先在隔离的 DSH 配置中检查组合，再在 Desktop profile 中安装测试。

## 隐私与安全

- 本地读取不等于允许上传。上传到像素蛋糕或其他服务前必须针对具体文件获得确认。
- 不操作登录、验证码、密码管理器、安全设置或与修图无关的窗口。
- 不默认改变人物身份特征、体型或纪实真实性。
- 原图保持不变；输出到单独目录并保留可编辑母版。
