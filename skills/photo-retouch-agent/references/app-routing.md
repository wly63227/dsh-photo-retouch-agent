# Photoshop 与像素蛋糕分工

## 优先 Photoshop

- 精确裁剪、透视和几何校正。
- 复杂选区、蒙版、物体移除、合成和背景修复。
- 局部明暗塑形、颜色分级、精细皮肤修复和逐像素瑕疵处理。
- 需要图层、智能对象、通道或可编辑母版的工作。

## 优先像素蛋糕

- 经用户同意上传后的多人像批量基础处理。
- 同一拍摄环境中需要统一曝光、肤色和基础精修的成组照片。
- 先做代表样片，再把已确认配方同步到整批。

## 组合流程

常见顺序是：只读筛选 → 用户确认入选 → 像素蛋糕代表样片 → 用户确认 → 批量基础版本 → Photoshop 精细局部 → 用户逐步确认 → 最终导出。

如果源文件需要复杂合成、精确透视或严格色彩管理，可直接从 Photoshop 开始。软件选择必须基于本次图像、数量、隐私和交付用途说明，不要机械套用。
